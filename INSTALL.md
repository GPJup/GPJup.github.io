# GPJup Analytics

## Подключить общие счётчики
1. Создайте проект в Supabase.
2. Откройте SQL Editor и запустите весь файл `supabase-setup.sql`.
3. В настройках проекта скопируйте Project URL и anon/public key.
4. Вставьте эти два значения в `analytics.js` и `stats.js`. Используйте только anon/public key, никогда не вставляйте service_role/secret key.
5. После этого статистика начнёт собираться с ПК и телефона в одну базу.

Панель: https://gpjup.github.io/stats.html

## Счётчики
- page_views: открытие сайта. Быстрый переход index.html -> mobile.html не учитывается дважды.
- Клики по Steam, Spotify, Discord, TikTok и Telegram.
- Клики по кнопкам управления на ПК: музыка, следующий трек, звук и настройки.

## Важно
Пароль проверяется в браузере и не является настоящей защитой. Публичную функцию счётчика можно накручивать. Не храните конфиденциальные данные. Для настоящей защиты потребуется серверная авторизация и rate limiting.
