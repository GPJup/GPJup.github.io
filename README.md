# GPJup.github.io

Персональная страница GPJup.

1. Создай GitHub-репозиторий с именем `GPJup.github.io`.
2. Загрузи содержимое этой папки в корень репозитория.
3. В Settings → Pages выбери Deploy from a branch, `main`, `/ (root)`.
4. Сайт будет доступен на https://GPJup.github.io/

Замени `assets/avatar.svg` на свою настоящую аватарку. Если это PNG/JPG/WebP, поменяй src в index.html на соответствующий файл. Для полного эффекта с цветами аватарки можно дополнить JS извлечением цветов изображения.
